                SharePoint Files
                
            

            

                

                    Every SharePoint spreadsheet the app reads. Each file is checked for changes on its own
                    interval: the app asks SharePoint when the file was last saved (a quick call that does not
                    open the workbook) and only downloads it when it has been saved since the copy it holds.
                    Pages are drawn from that copy straight away; a newer copy is downloaded in the background
                    and the page redraws when it arrives. Checks only happen while someone is using the site.
                

                

                    KPI Daily Metrics files can be added and deleted here: a date column plus
                    number columns, one row per day. Every column holding only numbers becomes a KPI chart metric.
                    The Daily Buyers Sheet and Cars Bought files can be edited
                    and switched off but not deleted, because Buying Requirements turns their rows into purchases.
